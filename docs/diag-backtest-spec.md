## 3. 前瞻報酬從哪來

### 3.1 報酬口徑（寫死）

- 個股期距 h 報酬：`R_i(D,h) = close_i(t0+h) / close_i(t0) − 1`，h ∈ {10（主）, 3（附）} 個**交易日**。
- **主口徑 t0 = D**（訊號資料日收盤，「資訊含量」口徑）；**可執行口徑 t0 = D+1**（使用者開盤前看到燈號、
  以 D+1 收盤進場，對應 §2.2 的無前視結論）。兩者都算，**判定以主口徑為準、可執行口徑作穩健性檢查**
  （§6.3）；這個分工屬待裁定事項（§10-1），使用者若要改以 D+1 為主，必須在跑之前改本檔。

## 4. 樣本量與自相關

### 4.1 規模

約 57 個資料日 × 1,200 檔。各規則觸發筆數見 §2.4（T+10 可實現期內欄）。

### 4.2 重疊與有效樣本

- T+10 相鄰資料日的報酬窗重疊 9/10，**57 天的獨立時間點只有約 57/10 ≈ 5.7 個**。
  取每 10 個交易日一個資料日（起點 07-17）只得 6 天：07-17、07-31、08-14、08-28、09-11、09-29。
- 同日內個股報酬高度共變（大盤、產業因子），所以**有效樣本受限於時間點數，不是 6 萬筆**。
- 期間只有約 3 個月、一段「7 月修正 → 8～10 月上漲 → 10 月中回落」的行情（`market.ma20/dd60` 逐日實查），
  結論**只代表這段行情**。

### 4.3 處理方式（寫死）

1. **先在每日做橫斷面**，把一天濃縮成一個數：`s_D = mean(e | 觸發, D) − mean(e | 未觸發且非 null, D)`。
   這樣同日共變被吸收，序列 `{s_D}` 的依賴只剩時間重疊。
2. **主推論：移動區塊 bootstrap（moving block bootstrap）對日序列重抽**，區塊長度＝h（T+10 用 10、T+3 用 3），
   10,000 次，亂數種子固定 `20261023`，取 2.5／97.5 百分位為 95% CI；雙尾 p 值＝bootstrap 分布中與 0 反側的比例 ×2。
3. **穩健性：不重疊子樣本**——對 h 個起點偏移（0…h−1）各取每 h 日一點，算 `mean(s_D)`，報告 h 個值的中位數與正負號一致性。
4. **個股持續性**（F3／F4 特別嚴重）：報告每條規則觸發組的**不同代號數**，並另跑「以代號為群集的 bootstrap」作敏感度；
   主判定不依賴它，但若兩者 CI 一個不含 0、一個含 0，標「不穩健」。
5. 誠實限制：57 天、區塊長 10 只有約 5～6 個區塊，**bootstrap CI 本身不可靠（偏窄）**——這是資料量的硬限制，
   不是方法能補的（§8）。

## 5. 檢定設計

### 5.1 逐條規則（命題一）

對每條規則 r、主口徑（h=10、t0=D、全市場等權）：

- 樣本分組：觸發＝`test(s,m) === true`（C3 用**閘後**值，即畫面行為；閘前值另列）；對照＝`test === false`；
  `null` 兩組都不進（與畫面「資料不足不列入判定」語意一致），報告 null 筆數。
- 統計量：`Δ_r = mean_D(s_D)`（只計當日觸發 ≥5 筆且對照 ≥5 筆的日子）；95% CI 與 p 值依 §4.3。
- 輔助（不進判定）：觸發組 `e>0` 勝率 vs 對照組勝率、中位數差、T+3、加權指數基準、diag 宇宙等權基準、t0=D+1。
- 預期方向：紅燈規則 Δ<0、綠燈規則 Δ>0。
- **市場層級規則不做橫斷面檢定**：S2 直接判「不適用（無橫斷面）」，報告只列 S2=真／假兩類日子的
  全市場等權 T+10 報酬平均與日數，**不下結論**（獨立時間點 <6）。S1 同樣因只有 4 天而落入樣本不足。

### 5.2 紅黃綠整體排序（命題二）

- 每日算三組平均超額 `G_D, Y_D, R_D`（任一組當日 <5 筆則該日不計）。
- 主統計量：`Δ_GR = mean_D(G_D − R_D)`，block bootstrap 95% CI（同 §4.3）。
- 單調性：`Δ_GY = mean_D(G_D − Y_D)`、`Δ_YR = mean_D(Y_D − R_D)` 點估計與 CI；
  另算每日 Spearman 相關（紅=0、黃=1、綠=2 對 e）的日平均與 CI。

### 5.3 多重比較

- 命題一的檢定族＝**主口徑下、通過最小樣本門檻的規則**（最多 11 條：14 − F2 − S1 − S2，視門檻結果而定），
  以 **Holm–Bonferroni、族錯誤率 α=0.05** 校正雙尾 p 值。
- 命題二是單一事先指定的檢定，α=0.05，不與命題一合併校正。
- 所有輔助口徑（T+3、加權指數、D+1、敏感度）**一律描述性**，不做顯著性宣告、不參與判定。

### 5.4 最小樣本門檻（寫死）

一條規則要進入檢定族，必須**同時**滿足（以主口徑計）：
1. 觸發筆數 ≥ 300；
2. 進入 `s_D` 的日數 ≥ 20；
3. 不重疊子樣本（起點 0）中至少 3 個時間點有 ≥5 筆觸發；
4. 觸發組不同代號數 ≥ 30。

不滿足者判「**樣本不足，無法判定**」——**不等於「無效」**，報告不得寫成無效。
依 §2.4 的觸發數，**事前預期**落入樣本不足的有 F2（0 筆）、S1（4 天）；T1（29 天、24 筆不重疊）邊緣；
C1（38 筆不重疊）可能過門檻 3 但需實算。這是事前預期，不是結果。

## 6. 判定標準（事先寫死，比照 taiwan-flow-live-v2 `docs/line-cards-spec.md` §8 B1 的教訓）

### 6.0 寫死的理由與程序

taiwan-flow-live-v2 曾發生「`run_s2()` 取 max 後無條件宣告採用、沒有門檻」，看到結果才補門檻
（`docs/line-cards-spec.md:399-411`，2026-09-14 B1-1 裁示；同型的 `run_m1`／`run_s1` 仍未處理）。
本規格因此：
- 所有門檻、檢定、選版、口徑**都在本檔、在看到任何報酬之前寫定**。撰寫本檔時**未計算任何前瞻報酬**
  （§2.4 只數了觸發次數）。
- 結論行**只能由腳本依本節規則產出**，不得手改報告（同 live-v2 `f46aaf8` 的前例）。
- 實作後若發現本節某條規則無法執行（例如還原價取不到），只能照本檔已寫的退路走；新增退路要先改本檔、
  commit、再跑。

### 6.1 逐條規則判定

對通過 §5.4 門檻的規則：

| 判定 | 條件（全部成立） |
|---|---|
| **有鑑別力（方向正確）** | Holm 校正後 p < 0.05；Δ 方向符合預期；\|Δ\| ≥ **0.60%**（T+10） |
| **方向相反** | Holm 校正後 p < 0.05；Δ 方向與預期相反（不論大小） |
| **方向正確但幅度不足** | Holm 校正後 p < 0.05；方向正確；\|Δ\| < 0.60% |
| **無足夠證據** | Holm 校正後 p ≥ 0.05 |
| **樣本不足，無法判定** | 未過 §5.4 |
| **不適用** | S2（無橫斷面） |

0.60% 的依據：台股一買一賣成本約 0.1425%×2（手續費上限）＋0.3%（證交稅）＝0.585%，取整 0.60%。
這是**選擇的經濟門檻、不是量出來的**；與統計顯著獨立判斷。

### 6.2 紅黃綠排序判定

| 判定 | 條件 |
|---|---|
| **排序正確** | `Δ_GR` 95% CI 下界 > 0，且 `Δ_GY ≥ 0`、`Δ_YR ≥ 0`（點估計） |
| **僅兩端正確** | `Δ_GR` CI 下界 > 0，但 `Δ_GY` 或 `Δ_YR` 點估計 < 0 |
| **排序相反** | `Δ_GR` 95% CI 上界 < 0 |
| **無足夠證據** | 其餘 |

### 6.3 穩健性標記（不改判定，只加註）

主判定為「有鑑別力」「方向相反」「排序正確」「排序相反」者，若下列任一輔助口徑的**點估計正負號**與主口徑相反，
加註「**不穩健**」：t0=D+1、加權指數基準、diag 宇宙等權基準、§3.4 除權息敏感度、§4.3 第 3 點不重疊子樣本
（h 個偏移中過半反號）、§4.3 第 4 點代號群集 bootstrap（CI 是否含 0 與主口徑不一致）。

### 6.4 本回測不回答的問題（寫死）

- 規則組合是否比單條更好、要不要改門檻或改成加權打分（前提 4 已排除）。
- 「已驗證」標籤（P1、C3）原本引用的 v2 回測是否正確——本回測只量「在 diag 宇宙、這段期間」的表現。
