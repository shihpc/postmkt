## 3. 前瞻報酬從哪來

### 3.1 報酬口徑（寫死）

- 個股報酬：`R_i(D,h) = P_i(t0+h) / P_i(t0) − 1`，h ∈ {10（主）, 3（附）} 個**交易日**。`P` 的來源見 §3.4。
- **進場點**：
  - 主口徑 t0 = D（資訊含量）。
  - 可執行口徑 t0 = D+1（穩健性檢查）。
  - 〔r4〕已裁定（§10-2）：**t0=D 為主口徑進判定，t0=D+1 只作穩健性檢查**（§6.3 第 1 點）。
- 交易日序列以 taiwan-flows `data/meta.json` 的 `calendar` 為準。
- 超額報酬 `e_i = R_i − B`；主基準 B＝全市場等權，附基準＝加權指數。

**〔r2〕基準在現行主統計量中完全抵銷**
- 同一資料日、同一 h 的 B 對每檔相同。
- 因此 `s_D = mean(e｜觸發) − mean(e｜未觸發) = mean(R｜觸發) − mean(R｜未觸發)`，與 B 無關。
- 同理，§5.2 的 `G_D − R_D`、`G_D − Y_D`、`Y_D − R_D` 和每日 Spearman 也與 B 無關。
- 所以**在主統計量 A（橫斷面差）下，前提 2 的基準選擇對判定沒有任何作用**；換加權指數或 diag 宇宙等權，結果逐位相同。
- r1 §6.3 列的「加權指數基準」「diag 宇宙等權基準」兩項穩健性檢查是空的，r2 已刪除。
- 〔r4〕已裁定（§10-1）：**A 型進判定；B 型（觸發組對市場的絕對超額，基準在此才有作用）以兩個基準並列、只作描述**。

### 4.1 規模

### 4.2 重疊與有效樣本

### 4.3 處理方式（寫死，〔r2〕補足 bootstrap 細節）

**1. 每日橫斷面**：把一天濃縮成一個數 `s_D`（定義見 §5.1）。不合格的日子 `s_D` 記為缺值。

**2. 主推論：循環區塊 bootstrap（circular block bootstrap）**

| 項目 | 規定 |
|---|---|
| 索引 | 在**交易日曆索引**上進行，不在壓縮後序列上進行。序列長度 T＝該期距、該口徑下可實現的全部資料日數（主口徑 T+10 為 57），缺值日保留位置 |
| 區塊長度 | L = h（T+10 為 10、T+3 為 3） |
| 抽樣 | 每次重抽 ⌈T/L⌉ 個區塊起點，於 {0,…,T−1} 均勻抽取；區塊超過尾端時**循環接回開頭** |
| 截斷 | 串接後**截斷**到長度 T |
| 統計量 | 重抽序列中非缺值 `s_D` 的平均 Δ*_b。若一次重抽全為缺值則**重抽**（不計入 B），報告重抽次數 |
| 次數與種子 | B = 10,000。〔r3〕**亂數流**：每個（規則、統計量、口徑、bootstrap 類型）組合各自以 `numpy.random.default_rng(20261023)` **重新建立** rng 後才開始抽，彼此不共用亂數流；執行順序因此不影響任一組合的結果 |
| CI | Δ*_b 的 2.5／97.5 百分位，`numpy.percentile` 預設線性內插 |
| p 值 | `p = min(1, 2 · min( (1 + #{Δ*_b ≤ 0}) / (B + 1), (1 + #{Δ*_b ≥ 0}) / (B + 1) ))`，雙尾。〔r3〕這是由百分位 CI 反推的 p 值，**刻意不做虛無中心化**（不把 Δ* 平移到以 0 為中心），與 CI 判讀一致；最小可達 p ≈ 2/(B+1) ≈ 0.0002 |

**3. 穩健性：不重疊子樣本**
- 對 h 個起點偏移 k = 0…h−1，各取日曆索引 k, k+h, k+2h, … 的非缺值 `s_D` 求平均。
- 沒有任何非缺值點的偏移不計入。
- 計算與主估計 Δ̂ **反號**的偏移數 r、有效偏移數 n_o。
  - 〔r3〕「反號」指 `sign(偏移平均) = −sign(Δ̂) ≠ 0`：偏移平均恰為 0 **不算反號**；Δ̂ 恰為 0 時沒有方向可反，r＝0。
  - **r ≥ n_o / 2（含平手，例如 5:5）→ 標「不穩健」**；
  - 只有 r < n_o / 2 才算穩健。

**4. 穩健性：股票代號群集 bootstrap**
- 定義：〔r3〕代號集合 C＝該規則該口徑下，曾進入**觸發組或對照組**（不含 null）的全部代號之**聯集**（|C| = K）。每次以放回方式從 C 抽 K 個代號；被抽中 m 次的代號，其**全部**個股日以權重 m 計入。
- 重算每日的觸發組／對照組加權平均與 `s_D`，再對非缺值日平均得 Δ*_b。不做時間方向重抽。
- 〔r3〕當日是否合格（觸發 ≥5 且對照 ≥5）以該日各組的**不同代號數**計，不以加權筆數計；不合格記缺值。
- 〔r3〕若一次重抽後全部日子皆缺值，處理同第 2 點：重抽、不計入 B、報告重抽次數。
- B、種子（含〔r3〕亂數流規定）、CI、p 值公式同第 2 點。
- **判定一致性**：以群集 p 值取代主 p 值，在**同一檢定族**內做同樣的 Holm 校正。
- 若某規則「Holm 校正後是否 < 0.05」與主判定不同，標「不穩健」。

**5. 誠實限制**
- 57 天、區塊長 10 只有約 6 個區塊，bootstrap CI 本身不可靠（偏窄）。
- 這是資料量的硬限制，方法補不了（§8）。

## 5. 檢定設計

### 5.1 逐條規則（命題一）

**樣本分組**
- 觸發＝`test(s,m) === true`。C3 用**閘後**值（畫面行為），閘前值另列。
- 對照＝`test === false`。
- `null` 兩組都不進，報告 null 筆數。

**主統計量（A 型，現行）**
- `s_D = mean(R｜觸發, D) − mean(R｜對照, D)`，只計當日觸發 ≥5 筆且對照 ≥5 筆的日子（每檔每日一筆，故筆數＝不同代號數）。
- `Δ_r = mean(非缺值 s_D)`，CI 與 p 值依 §4.3。
- **與基準無關**（§3.1）。

**〔r2〕並列統計量（B 型；〔r4〕已裁定只作描述，§10-1）**
- `a_D = mean(e｜觸發, D)`，其中 `e = R − B`。
- `Δ^B_r = mean(非缺值 a_D)`：觸發組相對「市場」的絕對超額。只要求當日觸發 ≥5 筆。
- 這時前提 2 的基準才有作用。
- **只有 A 進判定**；B 在報告中以兩個基準各列一次，描述性呈現。

**輔助（不進判定）**
- 觸發組 `R>0` 的比例 vs 對照組。
- 中位數差、T+3、t0=D+1、§3.4 除權息敏感度、興櫃子樣本（§2.6）。

**預期方向**：紅燈規則 Δ<0、綠燈規則 Δ>0。

**市場層級規則不做橫斷面檢定**
- S2 判「不適用（無橫斷面）」。
- 報告只描述性列出 S2 為真／假兩類日子的全市場等權 T+10 報酬平均與日數，不下結論。

### 5.2 紅黃綠整體排序（命題二）

- 每日算三組平均報酬 `G_D, Y_D, R_D`。任一組當日 <5 筆，該日記缺值。

- **單調性**：`Δ_GY = mean(G_D − Y_D)`、`Δ_YR = mean(Y_D − R_D)` 的點估計與 CI。
- 以上與基準無關（§3.1）。
- 〔r2〕**每日 Spearman 相關（紅=0、黃=1、綠=2 對報酬）只作描述，不進判定**。

### 5.3 多重比較

## 6. 判定標準（事先寫死，比照 taiwan-flow-live-v2 `docs/line-cards-spec.md` §8 的 B1 教訓）

- 撰寫 r1／r2 時**未讀取任何報酬值**：§2.4、§3.4、§3.5 只數筆數與價格是否存在。
- 結論行只能由腳本產出，不得手改報告。

### 6.1 逐條規則判定

對通過 §5.4 的規則，以主統計量（A 型，§10-1 已裁定）判定：

| 判定 | 條件（全部成立） |
|---|---|
| **有鑑別力（方向正確）** | Holm 校正後 p < 0.05；Δ 方向符合預期；\|Δ\| ≥ **0.60%**（T+10） |
| **方向相反** | Holm 校正後 p < 0.05；Δ 方向與預期相反（不論大小） |
| **方向正確但幅度不足** | Holm 校正後 p < 0.05；方向正確；\|Δ\| < 0.60% |
| **無足夠證據** | Holm 校正後 p ≥ 0.05 |
| **樣本不足，無法判定** | 未過 §5.4 |
| **不適用** | S2（無橫斷面） |

0.60% 的依據：
- 一買一賣成本約為手續費上限 0.1425%×2 加證交稅 0.3%，合計 0.585%。
- 這是**選擇的經濟門檻，不是量出來的**。

### 6.2 紅黃綠排序判定

| 判定 | 條件 |
|---|---|
| **排序正確** | `Δ_GR` 95% CI 下界 > 0，且 `Δ_GY ≥ 0`、`Δ_YR ≥ 0`（點估計） |
| **僅兩端正確** | `Δ_GR` CI 下界 > 0，但 `Δ_GY` 或 `Δ_YR` 點估計 < 0 |
| **排序相反** | `Δ_GR` 95% CI 上界 < 0 |
| **無足夠證據** | 其餘 |

### 6.3 穩健性標記（不改判定，只加註；〔r2〕刪除兩項空檢查）

主判定為「有鑑別力」「方向相反」「排序正確」「排序相反」者，符合下列任一項時加註「**不穩健**」：
